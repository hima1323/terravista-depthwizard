# DepthWizard updates, 4 November 2026

## Main is now the glass UI
- `main` was fast-forwarded to `landing-sand-glass` (React glass UI at `/`, classic viewer at `/classic`).
- All the tools below were ported into it, in its own style: cards on each page with an on/off switch in the title,
  like the route finder.

## Easier to find
- **🔍 Find a tool** (top bar, **Ctrl K** or **/**): searches every tool on every page, opens the page and switches
  the tool on. Example: `drone` + Enter.
- Each card, when off, says in one line what the tool does.
- **Situation report** (Assess): the map, the 3D view and every tool result on one printable page (save as PDF).
